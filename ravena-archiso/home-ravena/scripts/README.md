# RAVENA - scripts do usuario

Esta pasta guarda scripts pessoais do usuario (ravena).

Uso: coloque aqui seus scripts e rode com `bash ~/scripts/meu-script.sh`
ou adicione ao PATH no `.bashrc`.

Exemplos de aliases ja disponiveis: `ll`, `horas`, `net`, `wifi`,
`conectar-wifi`, `navega`, `youtube`, `video`, `arquivos`, `llm`,
`specs`, `modelos`, `intel`, `rede`, `oobe`, `hardware`, `usb`, `saude`.
